# Archive of TON ecosystem maps

Maps of the Gram (TON) ecosystem that others published from 2022 on, kept in one place so the history
of the ecosystem can be traced: who was on the map, and when they dropped off. The names from these
maps were checked against [data/projects.csv](../data/projects.csv). Each project carries the maps it
appeared on in its `sources` column, and names we could not tie to a project are listed in
[data/unresolved.csv](../data/unresolved.csv).

The images belong to their authors and are not covered by this repository's licenses. They are kept
here for reference, with a link to where each one was published. If you are an author and want an
image removed or credited differently, open an issue.

## Add a map

Put the image here as `YYYY-MM-author.jpg` (largest version you can find), add a row to the table with
the link to where it was published, and, if you can, add its names to `data/`: link existing projects
by adding the map to their `sources`, and put the rest in `data/unresolved.csv`.
