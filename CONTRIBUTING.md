# Contributing

The easiest way is a form, no files to edit:

- [Report a wrong link](https://github.com/vitalikgpt/gram-ecosystem/issues/new?template=fix-link.yml)
- [Add a missing project](https://github.com/vitalikgpt/gram-ecosystem/issues/new?template=add-project.yml)

Pull requests are welcome too: edit `data/projects.csv`, say in the description where the right link comes from, and CI checks the rest.
